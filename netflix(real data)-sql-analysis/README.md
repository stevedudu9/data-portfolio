# 📺 Netflix SQL Analysis Project

## 📌 Overview
This project is a SQL-based data analysis of a Netflix dataset from KAGGLE containing over 8,800+ records of movies and TV shows.  
The goal is to explore content trends, distribution, and insights using SQL queries.

---

## 🗂️ Dataset Description

The dataset includes the following columns:

- show_id → unique ID for each title  
- type → Movie or TV Show  
- title → name of the show  
- director → director name  
- cast → actors involved  
- country → production country  
- date_added → date added to Netflix  
- release_year → original release year  
- rating → age rating (PG-13, TV-MA, etc.)  
- duration → length (minutes or seasons)  
- listed_in → genre/category  
- description → short summary  

---

## 🎯 Project Objectives

- Understand content distribution on Netflix  
- Analyze trends in movies vs TV shows  
- Identify top countries producing content  
- Explore rating and genre patterns  
- Practice SQL aggregation and joins  

---

## 🧠 SQL Concepts Used

- SELECT queries  
- WHERE filtering  
- GROUP BY aggregation  
- ORDER BY sorting  
- LIMIT clause  
- JOIN concepts (if extended)  
- HAVING condition  
- Text filtering (LIKE)  
- Aggregate functions (COUNT, AVG)

## 📊 Key Analysis Performed

### 1. Content Type Distribution
Compared number of Movies vs TV Shows.

### 2. Country Analysis
Identified top countries producing Netflix content.

### 3. Release Trends
Analyzed how content evolved over time.

### 4. Ratings Distribution
Explored audience rating categories.

### 5. Genre Analysis
Found most common genres and categories.

### 6. Director Analysis
Identified directors with the most titles.

### 7. Content Trends
Filtered latest and oldest content.

---

## 📈 Key Insights

- Movies make up the majority of Netflix content  
- The United States is the largest content producer  
- TV-MA and TV-14 are the most common ratings  
- Content production increased significantly after 2015  
- A small number of directors contribute a large number of titles
