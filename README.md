## Technology stack

Python, SQL, pandas, NumPy, scikit-learn, Streamlit, statistical modelling, data visualisation, and Jupyter notebooks.

## Run locally

```bash
git clone https://github.com/stevedudu9/data-portfolio.git
cd data-portfolio
python -m pip install -r requirements.txt
```

Open the relevant project folder for its project-specific instructions and dependencies.

## Project structure

```text
projects/    Featured and earlier project source materials
exercises/   SQL practice exercises
README.md    Portfolio index
```

## Methodology and validation

Projects use reproducible notebooks or scripts, transparent preprocessing, exploratory analysis, model evaluation appropriate to the use case, and written interpretation of results. See each project for dataset, validation, and limitation details.

## Limitations and future improvements

The portfolio combines projects with different datasets, deployment models, and maturity levels. Future updates will focus on clearer reproducibility notes and refreshed project outcomes; no additional dashboard projects are planned in this index.
