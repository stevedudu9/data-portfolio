# 🎬 Movies JOIN SQL Analysis Project

## 📌 Overview
This project demonstrates how to use SQL to analyze a movie dataset using multiple tables and JOIN operations.  
It simulates a real-world relational database where movies are connected to their directors.

---

## 🧠 Objectives
- Learn how relational databases work
- Practice SQL JOIN operations
- Perform data analysis using GROUP BY, WHERE, ORDER BY
- Extract insights from structured data

---

## 🗂️ Dataset Description

This project uses two tables:

### 🎥 movies table
Stores movie information:
- movie_id
- title
- year
- director_id

### 🎬 directors table
Stores director information:
- director_id
- director_name

---

## 🔗 Key SQL Concepts Used

- CREATE TABLE
- INSERT INTO
- SELECT
- JOIN
- WHERE filtering
- GROUP BY aggregation
- ORDER BY sorting
- LIMIT

---

## 📊 Key Queries Performed

### 1. Combine Movies with Directors (JOIN)
Shows each movie with its director name.

### 2. Count Movies per Director
Finds how many movies each director has made.

### 3. Filter Recent Movies
Shows movies released after 2022.

### 4. Sort Movies by Year
Displays latest movies first.

### 5. Top Latest Movies
Returns the most recent films in the dataset.

---

## 📈 Insights
- Directors like Denis Villeneuve and Christopher Nolan appear in recent high-profile movies.
- Most movies in this dataset are from 2021–2024.
- JOIN helps connect related data across tables for meaningful analysis.
