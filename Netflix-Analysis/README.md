# 🎬 Netflix Data Analysis Project

## 📌 Project Overview
This project analyzes Netflix movies and TV shows dataset using Python.  
The goal is to explore content distribution, trends, and patterns in Netflix’s library.

---

## 🛠️ Tools Used
- Python
- pandas 📊 :contentReference[oaicite:1]{index=1}
- matplotlib 📈 :contentReference[oaicite:2]{index=2}

---

## 📂 Dataset
The dataset contains approximately 8800+ Netflix titles including:
- Movies and TV Shows
- Directors and Cast
- Countries
- Ratings
- Release Year
- Duration

---

## 📊 Key Analysis Performed

### 1. Movies vs TV Shows Distribution
Shows the proportion of Movies and TV Shows on Netflix.

### 2. Top Countries
Identifies countries producing the most Netflix content.

### 3. Ratings Distribution
Analyzes audience rating categories (TV-MA, TV-14, etc.)
