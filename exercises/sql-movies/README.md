# SQL Movie Exercises

These small exercises show a progression through core SQL concepts. They are grouped here as learning material so the portfolio's featured projects remain focused.

| Exercise | Concepts |
| --- | --- |
| [01 — Pixar basics](01-pixar-basics/) | `SELECT`, `WHERE`, `LIKE`, `DISTINCT`, `ORDER BY`, `LIMIT`, `OFFSET` |
| [02 — Movie aggregations](02-movie-aggregations/) | Table creation, filtering, `COUNT`, `AVG`, grouping, top results |
| [03 — Movie joins](03-movie-joins/) | Relational tables, joins, grouping, filtering, sorting |

The exercises use SQLite-compatible syntax. Exercise 01 expects a Pixar `movies` table; exercises 02 and 03 include their own setup data or database.
