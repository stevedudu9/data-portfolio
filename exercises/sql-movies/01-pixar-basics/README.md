# 🎬 Pixar Movies SQL Analysis Project
## 📌 Project Overview
This exercise explores a small Pixar movie dataset using SQLite. The goal is to extract information with filtering, sorting, pattern matching, and duplicate removal. `queries.sql` includes the table setup and sample rows, so it can be run from start to finish in a new practice database.

## 🧠 Skills Learned
The exercise covers `SELECT`, `WHERE`, `LIKE`, `ORDER BY`, `DISTINCT`, `LIMIT`, and `OFFSET`—the core building blocks of SQL data retrieval.
