# Movie Aggregation Exercise

This SQLite exercise creates a small 2020s movie table and practices filtering, grouping, aggregation, sorting, and top-result queries.

## Files

- `queries.sql` rebuilds the sample table and runs the analysis.
- `movies.db` is a saved SQLite database from the exercise.

Box-office values in the sample data are approximate USD millions and are included for SQL practice, not authoritative financial analysis.

Run `queries.sql` in SQLite or DB Browser for SQLite. The script starts with `DROP TABLE IF EXISTS`, so it can be rerun safely against a practice database.
