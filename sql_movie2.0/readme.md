# 🎬 2020s Movies SQL Analysis Project

## 📌 Overview
This project analyzes modern movie data using SQL, focusing on box office performance, directors, and trends in the 2020s film industry.

---

## 🧠 Skills Used
- SQL SELECT queries  
- Filtering with WHERE  
- Aggregation with GROUP BY  
- Sorting with ORDER BY  
- LIMIT for top results  

---

## 📊 Key Insights
- James Cameron and Christopher Nolan produced high-grossing films  
- Movies like Avatar 2 and Spider-Man performed extremely well  
- Box office varies significantly by director and genre  

---

## 🚀 Conclusion
This project demonstrates how SQL can be used to analyze real-world entertainment data and extract meaningful insights.
