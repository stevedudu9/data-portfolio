# 🏠 House Price Prediction (Linear Regression)

## 📌 Overview
This project predicts house prices using machine learning. A linear regression model is used to understand the relationship between house features and sale price.

---

## 🧠 Features Used
- Gross Living Area (GLA)
- Number of Bedrooms Above Grade
- Full Bathrooms Above Grade

---

## 🧪 Model Used
- Linear Regression model
- Train-test split applied
- Model evaluated using RMSE and coefficients

---

## 📊 Results
- Model coefficients show how each feature affects house price
- RMSE indicates average prediction error (~46,000)
- Some outliers affect prediction accuracy

---

## 📈 Key Insights
- Larger living area generally increases price  
- Some high-area houses still have low prices (outliers)  
- Model performs reasonably but can be improved with more features  

---

## 🚀 Conclusion
This project demonstrates basic regression modeling for predicting house prices and understanding relationships between features and price.
