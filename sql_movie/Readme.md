# 🎬 Pixar Movies SQL Analysis Project
## 📌 Project Overview
This project explores a Pixar movies dataset using SQL. The goal is to learn how to extract meaningful insights from structured data using basic SQL queries such as filtering, sorting, pattern matching, and removing duplicates. Instead of manually browsing data, SQL allows us to ask structured questions and retrieve only relevant results efficiently.

## 🧠 Skills Learned
In this project, I practiced SQL fundamentals including SELECT statements for retrieving data, WHERE clauses for filtering specific conditions, LIKE operator for pattern matching, ORDER BY for sorting results, DISTINCT for removing duplicate values, and LIMIT with OFFSET for controlling the number of rows returned. These are the core building blocks of SQL data analysis.
